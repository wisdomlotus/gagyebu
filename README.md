# 가계부 (휴대폰 설치형 웹앱)

카드 승인 문자를 붙여넣으면 날짜·금액·사용처를 자동으로 기록하는 지출 전용 가계부입니다.
앱스토어 없이 **홈 화면에 추가**해서 일반 앱처럼 씁니다. 인터넷이 없어도 열려요.

## 기능
- **캘린더**: 한 달 달력에 날짜별 지출 합계, 위쪽에 그 달 총합 / 좌우로 밀면 달 이동
- **지출 입력**: 직접 입력, 또는 카드 문자 붙여넣기(여러 건 한꺼번에 가능)
  - 신한·KB국민·삼성·현대·롯데·우리·하나·NH·카카오뱅크 등 일반적인 승인 문자 형식 인식
  - 누적·잔액 금액은 무시하고 승인 금액만 기록, 취소 문자는 합계에서 빼기
  - 이미 기록한 문자는 "중복"으로 표시하고 체크 해제
  - 해외결제(USD 등)는 원화 금액만 직접 적으면 됨
  - 사용처를 보고 카테고리 자동 선택, 한 번 바꾼 카테고리는 다음부터 기억
- **카테고리별**: 월간/연간 상위 카테고리 합계와 비율 → 누르면 세부 카테고리별 합계 → 누르면 내역
- **설정**: 상위·세부(하위) 카테고리 추가·수정·삭제·순서 변경, 백업 내보내기/불러오기
  - 세부 카테고리를 지우면 그 내역은 상위 카테고리로, 상위 카테고리를 지우면 세부까지 함께 지워지고 내역은 '미분류'로 이동

## 휴대폰에 설치하기

### 1단계: 인터넷 주소에 올리기 (한 번만)
홈 화면 설치는 https 주소가 있어야 해서, 이 폴더를 무료 호스팅에 올립니다. 둘 중 편한 것 하나만 하세요.

**A. Netlify Drop (가장 간단)**
1. 컴퓨터 브라우저에서 https://app.netlify.com/drop 접속 (무료 가입 필요)
2. 이 `가게부` 폴더를 통째로 끌어다 놓기
3. 생긴 주소(예: `https://xxxx.netlify.app`)를 휴대폰으로 보내기

**B. GitHub Pages**
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올리기
2. 저장소 Settings → Pages → Branch를 `main` / `root`로 저장
3. 몇 분 뒤 생기는 `https://아이디.github.io/저장소이름/` 주소 사용

### 2단계: 갤럭시에 설치
1. 갤럭시에서 **Chrome** 앱으로 주소 열기 (삼성 인터넷보다 Chrome을 권장: 문자 공유 기능이 확실히 동작)
2. 화면 아래 "앱 설치" 안내가 뜨면 **설치**, 안 뜨면 오른쪽 위 ⋮ → **앱 설치** (또는 **홈 화면에 추가 → 설치**)
3. 앱 목록과 홈 화면에 **가계부** 아이콘이 생기고, 일반 앱처럼 전체 화면으로 열려요.

### 카드 문자 넣는 방법 (갤럭시)
- **가장 빠른 방법 – 공유**: 삼성 메시지 앱에서 카드 문자를 길게 누르기 → **공유** → **가계부** 선택
  → 가계부가 열리면서 바로 분석 화면이 뜨고, **저장**만 누르면 끝.
  (처음엔 공유 목록 뒤쪽에 있을 수 있어요. 한 번 쓰면 앞쪽으로 올라와요.)
- **복사해서 붙여넣기**: 문자를 길게 눌러 **복사** → 가계부 **+ → 카드 문자 붙여넣기** → **📋 클립보드에서 붙여넣기**
  (처음 한 번 클립보드 접근을 허용해 주세요.) 여러 문자를 한꺼번에 선택해서 복사해도 돼요.

## 꼭 알아두기
- 기록은 **그 휴대폰 안에만** 저장됩니다(서버로 보내지 않음). 휴대폰을 바꾸거나 앱/브라우저 데이터를 지우기 전에
  **설정 → 백업 파일 내보내기**를 해 두고, 새 휴대폰에서 **백업 파일 불러오기**로 옮기세요.
- 아이폰은 Safari에서 연 페이지와 홈 화면 앱의 저장공간이 따로라서, 반드시 홈 화면 앱으로 기록하세요.
- 앱을 고친 뒤 다시 올리면, 휴대폰에서 앱을 껐다 켤 때 새 버전이 적용됩니다.
